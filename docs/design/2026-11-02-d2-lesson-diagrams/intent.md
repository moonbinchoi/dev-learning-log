# Intent: Lesson diagrams with D2
Status: implemented · Date: 2026-11-02

이미 구현된 작업의 회고 문서다. 사전 설계 기록이 아니다. 구현은 끝났지만 2026-11-02 현재 실제 레슨에 쓰인 적은 없다. 승인은 2026-11-02 사용자의 전체 승인 지시에 따른다.

## Problem
학습자인 사용자는 요청이 구성 요소를 어떻게 거쳐 흐르는지를 글만으로 따라가기 어려웠다. 강의 자료와 설명을 곱씹으면 도출할 수는 있지만, 이해하는 데 불필요한 시간이 너무 많이 들었다. 레슨에 그림을 반복해서 넣는 방법도 없어서, 1회차에서는 교재 그림이 있는데도 그림을 손으로 그렸다.

## Goals
- G1. 2회차 이후 레슨은 핵심 원리를 그림으로 보여 주고, 사용자가 2회차 후 피드백에서 흐름 이해가 쉬워졌는지 판단한다.
- G2. 교재나 공식 자료에 쓸 그림이 있으면 그 그림을 쓰고, 없을 때만 새로 그린다.
- G3. 사용자는 모든 그림을 링크로 이동하지 않고 레슨 안이나 강의 중에 바로 본다.
- G4. 5~7단계 요청 흐름을 번호, 판단 주체, 분기, 단계별 데이터 위치와 함께 그리고, 단계마다 활성 구성 요소를 강조해 볼 수 있다.
- G5. 그림 하나를 텍스트 원본과 명령 하나로 만들고, 좌표를 손으로 맞추지 않는다.
- G6. 그림은 next-ai-draw-io 갤러리처럼 파스텔 역할 색, 묶음 상자, 선 종류로 구분돼 보인다.
- G7. 그림이 들어간 레슨은 라이트와 다크 테마, 500px 폭에서 기존 레슨 검토를 통과한다.

## Non-goals
- 1회차 등 기존 레슨에 그림을 소급 적용하지 않는다.
- Figma와 캔버스 도구를 도입하지 않는다.
- 그림 테마에 아이콘을 넣지 않는다.
- 전역 설치, PATH 변경, 제3자 스킬 추가를 하지 않는다.

## Constraints and assumptions
- 프로젝트 안에만 설치한다.
- 교재는 유료 자료이므로 본문과 그림을 외부 서비스에 올리거나 artifact로 공개하지 않는다.
- 레슨은 외부 리소스 없이 읽히는 한국어 HTML이고, VS Code 내장 브라우저에서 라이트와 다크 테마, 500px 폭까지 읽는다.
- Claude 채팅 패널에는 이미지가 표시되지 않으므로 강의 중 그림은 VS Code 에디터 탭으로 연다.
- 그림 생성은 Windows 전용이다. 레슨을 이 PC에서 만들기 때문이다.
- 강의 세션이 진행 중이면 트랙 파일을 고치지 않는다.
- Assumption: 이 PC의 맑은 고딕으로 한글이 표시된다. 다른 PC에서는 시험하지 않았다.
- Assumption: VS Code 내장 브라우저의 표시가 시험에 쓴 headless Chrome과 같다. 내장 브라우저에서는 시험하지 않았다.
- Assumption: 폭 720 그림의 글자는 500px 화면에서 약 9px로 작아져도 읽을 수 있다. 2회차 첫 그림에서 확인한다.
