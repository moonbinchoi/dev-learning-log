# Intent: Korean prose rules and check with im-not-ai
Status: implemented · Date: 2026-11-02

이미 구현된 작업의 회고 문서다. 사전 설계 기록이 아니다. 구현은 끝났지만 2026-11-02 현재 실제 강의 세션에서 동작한 적은 없다. 승인은 2026-11-02 사용자의 전체 승인 지시에 따른다.

## Problem
강의 자료와 채팅의 글이 AI 문체로 읽혔다. 말은 되지만 사람이 이해하기 편한 글이 아니어서, 사용자는 글을 읽고 문맥을 이해하는 데 불필요한 시간이 든다고 느꼈다.

## Goals
- G1. Claude가 강의 자료와 강의 중 채팅을 쓸 때 한국어 문체 규칙이 적용된다. 채팅은 사후 수정이 닿지 않으므로 작성 시점에 적용돼야 한다.
- G2. 레슨 검토 때 같은 글에는 항상 같은 값이 나오는 문체 수치를 근거로 볼 수 있다. 수치는 통과 기준이 아니다.
- G3. 원본 저장소가 갱신되면 무엇이 바뀌는지 먼저 확인한 뒤 어렵지 않게 반영할 수 있다.
- G4. 도구 파일은 프로젝트 파일과 섞이지 않고 한 폴더에 모이며, 별도 스킬처럼 관리하고 제거할 수 있다.
- G5. 프로젝트 안의 문서만 읽어도 출처, 기준 커밋, 가져온 파일, 제외한 규칙, 갱신과 제거 방법을 알 수 있다.

## Non-goals
- 글을 자동으로 고쳐 쓰는 재작성 파이프라인과 에이전트를 도입하지 않는다.
- 패턴 수치로 통과와 불합격을 자동 판정하지 않는다.
- 목록, 번호, 표를 없애는 규칙(C-2, C-5, C-9, C-10, J-1)은 적용하지 않는다.
- 플러그인 설치, 포크, 별도 저장소로 관리하지 않는다.
- 도구 변경의 git 이력은 남기지 않는다. "별도 추적"은 기준 커밋과 프로젝트 안 문서로 충족한다.

## Constraints and assumptions
- 이 프로젝트에 한해 설치한다.
- 필요한 파일만 가져와 프로젝트 안의 별도 폴더에서 관리한다.
- 코드, 인라인 코드, HTML 태그, 식별자, 명령, 경로, URL, 인용된 프로그램 출력은 규칙의 적용 대상에서 보호하고, 레슨의 목록, 번호, 표는 유지한다.
- 도구 폴더는 프로젝트 규칙을 따른다. git에 넣지 않고 버전을 프로젝트 버전 목록에 등록한다.
- 강의 세션이 진행 중이면 트랙 파일을 고치지 않는다.
- Assumption: 문체 규칙은 실제 강의 세션에서도 로드된다. 격리된 시험 프로젝트와 이 프로젝트의 비강의 세션에서만 확인했다.
- Assumption: 앞으로의 원본 갱신도 규칙 파일 구조를 유지한다. 과거 52개 커밋 재현에서 최근 29개는 통과했고, 오래된 23개는 아무것도 적용하지 않고 실패했다.
