# Mission: 스프링 백엔드 취업 준비

## Why
다른 직종에서 일한 2년의 개발 공백을 끝내고 스프링 백엔드 개발자로 취업한다. 면접에서 보여줄 포트폴리오 프로젝트가 있어야 하고, 각 기술을 "왜 그렇게 쓰는지"까지 설명할 수 있어야 한다.

## Success looks like
- 미니 프로젝트 "상품 주문 관리 서비스"(`shop`)를 처음부터 끝까지 직접 만들고, 회차별 커밋 이력과 README로 보여줄 수 있다.
- 회차마다 나온 면접 질문(예: 필터 vs 인터셉터, `@Transactional` 프록시 원리, 체크 vs 언체크 예외)에 "왜?"까지 답할 수 있다.
- 스프링 MVC 2편, 스프링 DB 1편 범위의 기능을 교재 없이 구현할 수 있다.

## Constraints
- 교재: 김영한 「스프링 MVC 2편」, 「스프링 DB 1편」(인프런 유료 자료, 개인 학습용).
- 개발 환경: VSCode. 교재 버전이 아니라 최신 안정 버전(Spring Boot 4.1.1, Java 25 LTS).
- 빌드와 실행은 shop의 dev container 안에서 한다.
- MVC2 1~6장은 외부 강의로 수강했다. 이 범위는 리마인드만 한다.
- 1세션 = 1회차.

## Out of scope
- JPA, Spring Security: 교재 범위 밖. 과정을 마친 뒤의 다음 주제.
