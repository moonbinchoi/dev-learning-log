용어집

spring-backend 트랙의 모든 레슨은 이 용어를 쓴다. 처음 나온 회차를 괄호에 적는다.

용어뜻
모델컨트롤러가 뷰(템플릿)에 넘기는 데이터 묶음. model.addAttribute("item", item)으로 넣으면 템플릿에서 ${item}으로 읽는다. 리다이렉트하면 사라진다. (1회차)
도메인 객체서비스가 다루는 핵심 대상을 나타내는 객체. 예: Item. 폼 객체와 구분한다. (1회차)
경로 변수URL 경로 안의 {이름} 자리(URI 템플릿 변수). /items/{itemId}의 itemId. 컨트롤러에서 @PathVariable로 받는다. (1회차)
PRG (Post/Redirect/Get)POST를 처리한 뒤 뷰를 바로 그리지 않고 리다이렉트로 응답해, 브라우저가 결과 페이지를 GET으로 다시 요청하게 하는 패턴. 새로고침해도 POST가 다시 전송되지 않는다. (1회차)
리다이렉트서버가 "이 주소로 다시 요청하라"고 응답하고, 브라우저가 그 주소로 새 요청을 보내는 것. 컨트롤러에서 뷰 이름 앞에 redirect:를 붙인다. (1회차)
쿼리 파라미터URL의 ? 뒤 이름=값 쌍. 예: /items/1?status=true. 템플릿에서 ${param.이름}으로 읽는다. (1회차)
커맨드 객체th:object로 폼에 지정한 객체. 폼의 각 칸이 이 객체의 필드에 대응한다. (1회차)
선택 변수 식*{필드}. th:object로 고른 객체의 필드를 가리킨다. *{itemName} = ${item.itemName}. (1회차)
바인딩요청 파라미터(문자열)를 객체 필드의 타입으로 바꿔 넣는 것. @ModelAttribute가 한다. (1회차)
BindingResult바인딩·검증 오류를 담는 객체. @ModelAttribute 파라미터 바로 다음에 두면 오류가 나도 컨트롤러가 호출된다. 모델에 자동으로 담긴다. (1회차)
FieldError특정 필드 하나의 오류. 사용자가 입력한 값(rejectedValue)을 함께 보관해서, 폼을 다시 그릴 때 입력값이 남는다. (1회차)
typeMismatch바인딩에서 타입 변환이 실패했을 때 스프링이 만드는 FieldError의 오류 코드. 예: 숫자 칸에 abc. (1회차)
Bean Validation필드에 @NotBlank·@Max 같은 애너테이션을 달아 검증 규칙을 선언하는 표준(Jakarta Validation). 구현체는 Hibernate Validator. (1회차)
폼 객체폼 데이터를 받기 위해서만 만든 객체(ItemSaveForm, ItemUpdateForm). 도메인 객체(Item)와 분리한다. (1회차)
1회차 레슨 폼·검증 요약
