# 이미지·컨테이너·VM: 핵심은 잡았고 용어와 인과가 흐리다

0회차(2026-10-09). `docker run hello-world` 두 번 후 `ps`/`ps -a`/`images`를 `0 2 1`로 정확히 예측했다. 처음엔 "두 번째 run은 만든 걸 다시 실행"이라 했다가 스스로 고쳤다. 면접 답에서는 다음이 흐렸다.

- 이미지를 "영구적인 데이터 모음"이라 했다. 공식 정의의 "불변"과 "실행에 필요한 파일·설정 패키지"가 빠졌다.
- 컨테이너를 "실행 중인 프로세스"라 했다. 방금 본 `Exited` 컨테이너와 모순된다.
- 컨테이너 vs VM에서 "격리가 약하다 → 가볍다"로 인과를 거꾸로 댔다. 둘 다 커널 공유의 결과다. 컨테이너를 "가상화된 공간"이라 불렀다.
- Windows 구조 질문에 처음엔 "WSL2" 한 단어만 답했다. 재답에서 서버가 리눅스라는 점은 말했지만, `docker` CLI가 Windows 클라이언트이고 `OS/Arch`가 근거라는 점은 빠졌다.

## Implications
- 1회차 회상 퀴즈: 이미지 정의("불변"), 종료된 컨테이너가 남는 이유, Windows에서 클라이언트·서버 구조와 그 근거.
- 1회차의 수명주기(created/running/exited)와 `docker start`가 "컨테이너 = 실행 중일 때만 존재" 오해를 바로잡는 자리다.
- 면접 답은 정의 단어 + 오늘 본 근거로 답하도록 계속 요구한다.
